# &#x20;# DriveNow — Car Rental Customer Application

# 

# \## Purpose

# DriveNow is a Flutter-based car rental customer application that lets a user browse vehicles, inspect specifications and prices in UGX, and submit a simulated rental request.

# 

# \## Course

# Capstone Project — Question 8 (Car Rental App)

# 

# \## Team Member

# \- Nabirye Topister

# 

# \## Required Screens

# 1\. Home

# 2\. Cars

# 3\. Car Details

# 4\. Booking

# 5\. Profile

# 

# \## Tech Stack

# \- Flutter (Dart)

# \- Static data only — no Firebase, no external API, no database

# \- No real payment, no real authentication

# \- Target: Web (Chrome) — project code is portable to Android/iOS

# 

# \## Setup

# 1\. Install Flutter SDK 3.x

# 2\. From the project folder run: `flutter pub get`

# 3\. From the project folder run: `flutter run -d chrome`

# 

# \## Folder Structure (planned)

# \- `lib/models/` — data model (Car)

# \- `lib/data/` — static sample cars and user profile

# \- `lib/theme/` — shared colour theme

# \- `lib/screens/` — the five required screens

# \- `lib/widgets/` — reusable cards and chips

# \- `assets/images/` — car and avatar images

# 

# \## Limitations

# \- Booking is simulated with a confirmation dialog

# \- Logout shows a dialog but does not clear any session

# \- All data is hard-coded; no state persists between app runs
